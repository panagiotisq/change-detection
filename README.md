3D & 2D LiDAR Change Detection FrameworkThis repository implements a robust pipeline for identifying structural modifications in multi-temporal point cloud data. The framework is designed to detect changes in dynamic environments (e.g., warehouses, urban scenes) by comparing data acquired at different time intervals.It features two distinct modules:2D Change Detection: A fast, quadtree-based approach for planar scans.3D Volumetric Analysis: An advanced workflow comparing geometric vs. semantic AI approaches to solve occlusion and ghosting artifacts.🏗️ 3D Change Detection (Volumetric)The 3D module focuses on detecting moved inventory (pallets, boxes) in a warehouse while filtering out static infrastructure (walls, racks). Three methods were implemented and evaluated to address the challenges of sensor noise and occlusion ghosting.1. Raw Geometric Registration (Baseline)Method: Aligns scans using Multiscale GICP (Generalized Iterative Closest Point) and performs a raw KD-Tree distance check ($r=0.4m$).Result: Effective for gross changes but suffers from high noise. Static walls are often flagged as changes due to sensor viewpoint shifts (sampling noise).2. Geometric Segmentation (RANSAC)Method: Applies iterative RANSAC plane fitting to detect and remove the floor and walls mathematically before comparing the clouds.Result: Removes floor noise but is "context-blind." It often accidentally removes flat objects (like pallets) or fails on uneven ground.3. Semantic AI Segmentation (Proposed Solution) 🚀Method: Utilizes Cylinder3D (Deep Learning) to semantically understand the scene.Infrastructure (Ignored): Walls (Class 12), Floor (Class 8-11).Inventory (Tracked): Fences/Cages (Class 13), Vegetation, and Unclassified objects.Result: Solves the "ghosting" problem. When a box is moved, the wall behind it is identified as "Building" and ignored, preventing false positives.Figure 1: 3D Change Detection results. Grey = Static Background, Red/Green/Blue = Changes over 3 different timestamps.🗺️ 2D Change Detection (Planar)This module implements a hierarchical spatial subdivision approach for 2D laser scans.Quadtree Aggregation: Recursively partitions the 2D plane into cells. Mismatches are aggregated at the cell level rather than per-point, improving robustness against small misalignments.Clustering: Detected changes are grouped using DBSCAN to identify meaningful object clusters.Figure 2: 2D Quadtree-based change detection map.🛠️ Installation & RequirementsSystem DependenciesROS2 Humble (for reading .mcap / .db3 bags)CUDA 11.8 (for Cylinder3D acceleration)Python LibrariesBashpip install open3d numpy rosbags
